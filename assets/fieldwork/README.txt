Put your fieldwork photos in this folder.

Suggested naming (matches fieldwork.html's placeholder slots):
  fieldwork-01.jpg
  fieldwork-02.jpg
  fieldwork-03.jpg
  fieldwork-04.jpg
  fieldwork-05.jpg
  fieldwork-06.jpg

You can use .jpg, .jpeg, or .png — just update the file extension
in fieldwork.html to match if you don't use .jpg.

Add more than 6? Copy one of the existing <button class="photo-card">
blocks in fieldwork.html, change the image filename, caption, location,
and date, and it'll appear in the grid automatically.
